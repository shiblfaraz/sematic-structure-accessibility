## ♿ Accessibility Features

The website has been developed with accessibility in mind.

### Semantic HTML5

The following semantic elements are used:

```html
<header>
<nav>
<main>
<section>
<article>
<footer>
```

These elements provide a meaningful structure for browsers and assistive technologies.

### ARIA Support

ARIA attributes are used where appropriate to improve accessibility for screen-reader users.

Examples include:

```html
<nav aria-label="Main navigation">
```

```html
<section aria-labelledby="section-heading">
```

```html
<form aria-label="Contact form">
```

### Keyboard Navigation

Interactive elements such as navigation links, form fields, and buttons can be accessed using the keyboard.

The website also provides visible focus indicators for keyboard users.

### Accessible Form

The contact form includes:

* Proper `<label>` elements
* Matching `for` and `id` attributes
* Required fields
* Appropriate input types
* Autocomplete attributes
* Keyboard accessibility
